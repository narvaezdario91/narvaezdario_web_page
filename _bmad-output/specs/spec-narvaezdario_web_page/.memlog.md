- (decision) El sitio actuará como un CV interactivo y sandbox para demostrar habilidades en AI/QA.
- (capability) CAP-1: Perfil y CV interactivo para visualizar experiencia (acordeones) y descargar PDF.
- (capability) CAP-2: Acceso directo a enlaces de validación externa (GitHub, LinkedIn).
- (capability) CAP-3: Blog técnico con lista de artículos, filtrado por categorías, y renderizado rico (MDX).
- (capability) CAP-4: Pestaña Sandbox IA en modo placeholder 'Próximamente'.
- (constraint) Uso de Astro (SSG), React (Islands), y Vanilla CSS (sin Tailwind).
- (constraint) Contenido manejado localmente con Astro Content Collections (Markdown/JSON).
- (constraint) Mobile-First y tipado estricto con TypeScript.
- (constraint) Despliegue en GitHub Pages mediante GitHub Actions.
- (decision) Posponer estado global y analítica compleja para la fase 1.1.
- (event) Self-Validate Pass 1 (Coherence): Passed. Todas las reglas de Spec Law cumplidas.
- (event) Self-Validate Pass 2 (Preservation): Passed. Todos los claims de valor de PRD y Arquitectura destilados exitosamente en SPEC y companions.
- (decision) El dominio para la Fase 1.0 será el subdominio por defecto .github.io.
- (decision) El placeholder del Sandbox IA tendrá un empty state estilizado con CSS puro, mostrando un sneak peek de los modelos de la Fase 1.1.
- (assumption) El volumen inicial de contenido será de máximo 5 artículos generados por IA, garantizando un impacto nulo en el tiempo de compilación estática.
