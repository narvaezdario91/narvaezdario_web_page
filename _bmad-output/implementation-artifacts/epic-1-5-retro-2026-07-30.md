## Éxitos y Fortalezas

1. **Coexistencia Arquitectónica:** Lograda una perfecta integración entre Tailwind CSS y las variables nativas HSL de CSS Vanilla previa.
2. **Interactividad Avanzada:** Implementación fluida de componentes de visualización de datos (Impact Grid, Experience Tabs) usando React Islands hidratadas bajo demanda.
3. **Diseño Bento & Marquee:** Excelente presentación visual modular para credenciales y la marquesina animada de tecnologías.

## Desafíos y Áreas de Mejora

1. **Gestión de Alcance en Layouts:** Garantizar que los resets de Tailwind no rompan estilos específicos preexistentes en la cascada.
2. **Optimización de Bundle:** Monitorear el empaquetado de librerías como Recharts para mantener los tiempos de carga en estándares SSG.

## Aprendizajes Clave (Key Insights)

- **Coexistencia de Estilos:** Integrar motores utilitarios sobre un sistema de tokens en variables CSS nativas es totalmente viable cuando se centralizan los tokens en `tailwind.config.mjs`.
- **Hidratación Parcial:** Mantener la filosofía de React Islands permite integrar gráficos interactivos sin sacrificar el puntaje Lighthouse.
