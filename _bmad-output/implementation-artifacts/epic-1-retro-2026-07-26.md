## Éxitos y Fortalezas

1. **Configuración Inicial y Automatización:** El pipeline de CI/CD quedó configurado exitosamente desde el día uno, permitiendo despliegues automáticos a GitHub Pages.
2. **Sistema de Diseño Consistente:** La adopción del esquema "Midnight Cobalt" mediante variables HSL nativas permitió un diseño sofisticado ("Glassmorphism") manteniendo el proyecto libre de dependencias pesadas.
3. **Fluidez Interactiva:** Se demostró un gran dominio de la arquitectura Islands de Astro (React) para los componentes dinámicos sin engrosar innecesariamente el JavaScript del cliente.

## Desafíos y Áreas de Mejora

1. **Especificidad CSS:** Dificultades iniciales al manejar la cascada global de CSS (ej. conflictos entre los colores de fondo del `html` vs `body`).
2. **Sincronización JS/CSS:** Inconvenientes al coordinar APIs del DOM (`scrollIntoView`) con las transiciones fluidas de CSS.
3. **Accesibilidad Integral:** Olvido inicial del atributo `prefers-reduced-motion` y soporte fallback `@supports`, requiriendo ajustes posteriores en el ciclo de revisión.

## Aprendizajes Clave (Key Insights)

- La **modularidad** y la separación estricta mediante CSS Modules es fundamental para escalar el sistema de diseño y evitar choques globales, tal y como destacó nuestro Project Lead.
- Construir animaciones siempre con fallbacks de accesibilidad desde la planificación, en lugar de tratarlo como un paso posterior.
