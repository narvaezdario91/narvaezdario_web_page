- (constraint) Framework principal: Astro (SSG) con TypeScript estricto, según lo definido en el PRD.
- (decision) AD-1 (Estilos): Uso de Vanilla CSS con variables HSL y CSS Modules. Binds: Toda la capa de estilización. Prevents: Acoplamiento a frameworks utilitarios (Tailwind) y facilita el control total sobre animaciones y micro-interacciones.
- (decision) AD-2 (Interactividad): Uso de React para los componentes interactivos en Astro (Islands Architecture). Binds: Toda la capa de interactividad del cliente. Prevents: Fragmentación de librerías JS y falta de escalabilidad de componentes complejos.
- (decision) AD-3 (Capa de Datos): Uso de Astro Content Collections (Local MD/MDX/JSON). Binds: Gestión de contenido del blog y datos estáticos del portafolio. Prevents: Dependencia de servicios externos (Headless CMS), asegurando velocidad de despliegue y tipado estricto.
- (decision) AD-4 (Deployment): Despliegue en GitHub Pages mediante GitHub Actions. Binds: Toda la infraestructura de producción y flujo CI/CD. Prevents: Uso de plataformas externas, consolidando el código y el alojamiento en un único proveedor como demostración de habilidades.
